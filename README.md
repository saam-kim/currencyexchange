# 🏄‍♂️ 환율 파도타기: 글로벌 자산가 (Global Wealth Creator)

고등학교 사회 및 경제 수업에서 학생들이 변동하는 환율과 국제 경제 뉴스 사이의 관계를 시뮬레이션을 통해 직접 경험할 수 있도록 돕는 에듀테크 교육용 웹 게임입니다. 

---

## 🏫 수업 운영 및 게임 흐름 (Lesson Flow)

이 시뮬레이션은 교사용 화면(전자칠판)과 학생용 화면(태블릿/스마트폰)이 상호작용하며 전개됩니다. **localStorage의 `storage` 이벤트 감지**를 이용하여 동일 기기 또는 동일 브라우저 환경에서 띄워진 여러 개의 탭이 실시간으로 동기화되어 작동하므로 별도의 웹 서버나 DB 구축 없이 즉시 수업에 사용할 수 있습니다.

### 1단계: 교사용 방 개설 (교사)
- 교사 화면에서 **[교사용 방 만들기]**를 선택합니다.
- 교사용 인증 **기본 PIN(`1234`)**을 입력하고 원하는 난이도 모드를 정한 뒤 방을 만듭니다.
- 칠판 화면에 **6자리의 수업 코드**(예: `348910`)가 크게 표시됩니다.

### 2단계: 모둠 로그인 및 대기 (학생)
- 학생들은 모둠별로 태블릿에서 **[학생 입장]**을 누릅니다.
- 칠판에 적힌 **수업 코드 6자리**와 자신들의 **모둠명**(예: `1모둠`, `환율원정대`)을 적고 로그인합니다.
- 로그인한 모둠은 교사 화면에 실시간으로 등록되며, 학생 기기는 대기 화면으로 바뀝니다.

### 3단계: 모둠 확정 및 게임 시작 (교사)
- 모든 모둠의 참여가 확인되면 교사는 대시보드 좌측의 **[모둠 확정 및 1R 개시]**를 클릭합니다.

### 4단계: 뉴스 분석 및 포트폴리오 리밸런싱 (학생 & 교사)
- **학생 화면**: 라운드에 따른 경제 뉴스(핵심 뉴스 & 비교 뉴스)를 분석합니다. 
  - 슬라이더와 숫자 입력을 활용하여 총 1억 원의 모둠 자산을 원화(KRW), 달러화(USD), 엔화(JPY)에 어떻게 분배할지 설정합니다. (세 통화 비중의 합은 **반드시 100%**여야 제출 가능)
  - 투자를 결정한 합리적 경제학적 근거를 서술형으로 텍스트 상자에 기술하고 제출합니다.
- **교사 화면**: 실시간으로 제출을 완료한 모둠 현황을 관찰할 수 있습니다. 교사는 화면상의 **[실시간 전략 훔쳐보기]** 기능을 활성화하여 제출을 마친 모둠의 비중 배치와 작성 근거를 읽어보며 라이브 코멘터리(수업 피드백)를 진행할 수 있습니다.

### 5단계: 라운드 마감 및 환율 변동 정산 (교사)
- 교사가 **[라운드 마감 및 환율 반영]**을 누르면 해당 라운드의 실제 환율 변동률이 적용되어 모둠 자산 가치가 실시간으로 업데이트됩니다.
- 학생 기기에도 정산 화면이 표시되며, 모둠별 자산의 흑자/적자 상황, 획득한 '뉴스 해석 점수(키워드 채점)', 탑재된 환율 변동 원리 해설을 확인합니다.

### 6단계: 라운드 반복 및 성찰 일지 작성
- 2라운드부터 5라운드까지 위 단계를 반복합니다.
- 5라운드가 끝나고 교사가 게임을 완전히 종료하면, 학생 화면에 **최종 성찰 일지(소감 및 환율 원리 분석)** 작성 칸이 생깁니다.
- 학생들이 성찰 작성을 완료하면 교사 대시보드 화면에 실시간으로 모둠원들이 작성한 소감이 업로드됩니다.

### 7단계: 최종 리더보드 및 피드백 (종합)
- 교사는 종합 랭킹 리더보드 탭을 활성화하여 최종 자산 순위, 누적 수익률, 누적 뉴스 해석 점수, 모둠별 선호 투자 성향 및 성찰을 다 함께 보며 피드백을 제공합니다.
- **[CSV 다운로드]** 버튼을 통해 전체 모둠 성적 기록을 보관할 수 있습니다.

## 💡 난이도 모드 안내

수업 대상 학년 및 성취 수준에 맞춰 세 가지 난이도를 제공합니다.
1. **기본 모드**: 뉴스 전문, 힌트 교과서 가이드, 핵심 개념 태그가 모두 제공되어 중학교 또는 입문 수업에 적합합니다.
2. **표준 모드**: 뉴스와 개념 태그가 제공되나 힌트는 숨겨집니다.
3. **평가형 모드**: 뉴스 헤드라인만 제공되므로, 학생들이 스스로 외부 충격에 의한 환율 인과관계를 유추해야 하는 모드입니다. (고등학교 심화 수업 추천)

## 🛠️ 기술 스택 및 로컬 실행 방법

### 기술 스택
- **Front-end**: React 18, Vite, Vanilla CSS
- **Icons**: Lucide React
- **Data Sync**: LocalStorage Web API (`storage` event listener)

### 개발 서버 실행 방법
1. **의존성 패키지 설치**
   ```bash
   npm install
   ```
2. **개발 모드 구동**
   ```bash
   npm run dev
   ```
3. **크롬 등 웹 브라우저에서 동시 활용 테스트**
   - 하나의 브라우저 창에서 `http://localhost:5173`을 열고 **[교사용 방 만들기]** 클릭 (PIN: `1234` 입력)
   - 새로운 브라우저 시크릿 창 또는 다른 탭에서 동일하게 `http://localhost:5173`을 열고 **[학생 입장]**을 클릭하여 코드를 적어 진행해 보세요. 실시간 탭 간 데이터 연동을 테스트할 수 있습니다.
